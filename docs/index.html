01 / USE CASES

One workspace. Several disciplines.

RoboForge helps organize the early stages of engineering work without pretending to replace specialized industrial systems or safety validation.

01 ROBOTICS
⬡

Prototype robot workflows

Inspect ROS 2 nodes and topics over rosbridge, subscribe to selected messages and review explicitly authorized publications.

ROS 2 · rosbridge
02 INDUSTRIAL DATA
▤

Explore machine telemetry

Browse a configured OPC UA address space and read values locally before designing higher-level tooling.

OPC UA · read-only
03 CONNECTED SYSTEMS
◉

Build IoT observability

Subscribe to MQTT-over-WebSocket topics, observe event traffic and publish only after human confirmation.

MQTT · EMQX
04 AI ASSISTANCE
✳

Draft and inspect code

Choose local Ollama or an optional external API. Generate drafts, inspect resulting files and review before deployment.

Ollama · OpenAI · DeepSeek
05 SIMULATION
◇

Observe simulated systems

Explore Isaac Sim-related ROS telemetry such as /clock in experimental workflows—without claiming scene-control support.

Isaac Sim · experimental
06 DEVICE EXPLORATION
▣

Inspect connected devices

Monitor authorized Arduino serial data, Home Assistant entities and selected enterprise API resources where available.

Arduino · Home Assistant · Siemens
07 SOFTWARE ANALYSIS
⌘

Inspect application structure

Use optional local REA to collect static analysis Evidence from selected JavaScript/Electron, .NET, Go and Rust artifacts with explicit authorization.

04 / PROVIDERS

Keep AI on your terms.

Local-first doesn't mean local-only. RoboForge defaults to Ollama; external model services are optional and explicitly selected in Settings. Credentials must stay private.

✳
Code generation is assistance, not deployment.

Results are reviewable text. Generated commands must not be executed on robots or machines without independent validation and operator approval.

05 / GET STARTED

Run locally.
Work deliberately.

Extract the source archive, install dependencies, run the automated tests and open the application. Node.js 20.19+ or 22+ and npm are required for the first build.

For Linux launchers, optional integrations and configuration, see the project README on GitHub. The website you are viewing is a project presentation, not the RoboForge application.

LINUX SHELL
npm --prefix frontend install
npm --prefix frontend run build
npm --prefix backend test
node backend/server.js
Open http://127.0.0.1:3001 after starting the server
!

Engineering tool. Not an industrial safety controller.

Frontend production build and real hardware, Siemens tenant, model provider and service integrations have not been independently verified in this presentation package. Local API health does not prove that connected equipment is available. Any live deployment requires separate authorization, safety review and acceptance testing.
